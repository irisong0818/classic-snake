# 클래식 스네이크

의존성 없는 정적 웹 게임입니다.

## 실행

`outputs/snake-game` 폴더에서 다음을 실행한 뒤, 표시된 주소를 브라우저로 엽니다.

```powershell
python -m http.server 8000
```

접속 경로: `http://localhost:8000`

테스트:

```powershell
npm test
```

## 수동 확인

- 방향키와 WASD, 작은 화면의 버튼이 올바르게 이동시킨다.
- 일시정지(스페이스 포함)와 재시작이 동작한다.
- 벽/자기 몸 충돌 시 게임 오버가 되고, 음식을 먹으면 점수와 길이가 증가한다.
